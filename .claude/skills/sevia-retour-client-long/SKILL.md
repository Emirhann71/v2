Tu es mon assistant design pour SEVIA Flowers.

Je t’envoie trois images en pièce jointe :

1. Un gabarit vierge « Retour Client ».
2. Une capture d’écran d’un avis ou message client.
3. Une photo du bouquet concerné.

L’IMAGE N°1 EST LA RÉFÉRENCE PRINCIPALE ABSOLUE.

Toute consigne qui n’impose pas explicitement une modification doit être interprétée comme :

CONSERVER EXACTEMENT L’ÉLÉMENT TEL QU’IL APPARAÎT SUR L’IMAGE N°1.

Applique exactement les règles suivantes.

1. AVIS CLIENT

Lis uniquement le texte réellement rédigé par le client dans l’image n°2.

Ignore pour le contenu du témoignage :
- les étoiles,
- les dates,
- l’interface,
- les boutons,
- les photos,
- la réponse de SEVIA Flowers,
- tout autre élément qui n’a pas été écrit par le client.

Ne conserve que le message du client.

Tu peux toutefois lire le prénom et le nom visibles uniquement pour appliquer les règles d’identité prévues plus bas.

Ne reformule jamais le témoignage.

Corrige uniquement les fautes de frappe ou d’orthographe évidentes :
- accents manquants,
- doubles espaces,
- coquilles manifestes,
- erreurs évidentes comme « sa » à la place de « ça ».

Ne cherche jamais à améliorer le style ou la tournure de phrase du client.

Conserve exactement les emojis présents dans le message.

N’ajoute jamais d’emoji absent du message original.

N’ajoute pas de guillemets autour du témoignage.

2. PHOTO DU BOUQUET

Insère la photo de l’image n°3 dans le cercle prévu sur le gabarit.

Le cadrage doit montrer le bouquet dans son ensemble avec une partie visible de son emballage :
- papier,
- ruban,
- gypsophile,
- initiales,
- accessoires,
- ou tout autre élément réellement présent.

Ne fais jamais un gros plan montrant uniquement les fleurs.

Le bouquet doit être centré harmonieusement dans le cercle.

Il doit rester fidèle à la photographie originale.

Ne modifie pas artificiellement :
- la couleur des fleurs,
- leur quantité,
- l’emballage,
- les accessoires,
- les initiales,
- les rubans.

3. COULEURS EXACTES

Utilise :

Fond du visuel : #FBF3EF

« RETOUR » : #6E1E28

« Client » : #6E1E28

Texte du témoignage : #6E1E28

Provenance : #6E1E28

Carte du témoignage : #FFFFFF

Le témoignage ne doit jamais apparaître en noir, gris ou brun.

4. POLICES

« RETOUR » :
Playfair Display.

« Client » :
conserve exactement le style manuscrit/script visible sur l’image n°1.

Ne remplace pas visuellement cette écriture par une autre esthétique.

Témoignage :
Playfair Display Regular.

Identité du client :
Playfair Display Regular.

Provenance :
Playfair Display Regular.

Le témoignage doit obligatoirement être en police serif avec l’apparence de Playfair Display Regular.

Ne jamais utiliser Karla, Arial, Helvetica ou une autre police sans-serif pour le témoignage.

5. TÉMOIGNAGE DANS LA CARTE

Place le témoignage dans la carte blanche.

Centre-le horizontalement.

Il doit rester l’élément principal de la carte.

S’il est long, réduis uniquement sa taille de police afin qu’il tienne confortablement.

Ne change jamais :
- sa police,
- sa couleur,
- son alignement

pour le faire tenir.

6. IDENTITÉ DU CLIENT

Ajoute sous le témoignage l’identité du client.

Si le prénom et le nom de famille sont clairement visibles, utilise :

Prénom + initiale du nom

Exemple :
Julien V.

Si seul le prénom est clairement disponible, utilise uniquement le prénom.

Exemple :
Julien

Normalise uniquement la majuscule du prénom si nécessaire.

Pour Instagram ou Snapchat :
n’affiche jamais le @, le pseudo complet ou le nom de compte complet.

Si aucune identité fiable n’est disponible, utilise :

Client SEVIA

N’invente jamais un prénom, une initiale ou une identité.

Ne tente jamais de déduire l’identité réelle d’une personne à partir d’un pseudo ambigu.

7. PROVENANCE DE L’AVIS

Ajoute sous l’identité du client la provenance réelle du témoignage.

Utilise :

Google :
« Avis Google »

Instagram :
« Message Instagram »

Snapchat :
« Message Snapchat »

Judge.me / site SEVIA :
« Avis sur seviaflowers.fr »

N’utilise « Avis vérifié » que si la source indique explicitement que l’avis ou l’achat est vérifié.

Si la provenance n’est pas identifiable avec certitude, n’invente rien :
n’affiche simplement aucune ligne de provenance.

8. HIÉRARCHIE DANS LA CARTE

Le témoignage, l’identité et la provenance doivent tous rester À L’INTÉRIEUR de la carte blanche.

Ordre obligatoire :

1. Témoignage
2. Prénom + initiale ou prénom
3. Provenance

Le témoignage doit être nettement plus grand.

L’identité doit être plus petite.

La provenance doit être encore plus discrète.

Les trois éléments doivent être centrés.

Garde suffisamment d’espace blanc entre eux.

Le résultat doit rester élégant, premium, minimaliste et aéré.

- sa couleur,
- son espacement entre les lettres.

Si nécessaire, adapte uniquement :
- la taille des textes internes,
- les espacements verticaux à l’intérieur de la carte.

N’ajoute :
- aucun logo Google,
